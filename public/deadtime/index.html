GET STARTED / 快速上手

三步，准备就绪。

先打开抖音，再把窗口交给 DeadTime。

  1. 01

    解压，打开

    下载后解压整个 ZIP，进入 DeadTime 文件夹，双击 DeadTime.exe。请保留同目录下的 _internal 文件夹。

  2. 02

    选择娱乐窗口

    打开抖音客户端或独立的抖音浏览器窗口。在控制台选择游戏，再点选择窗口，选中你要看的窗口。

  3. 03

    开始监测，回到游戏

    开启自动切换，点击开始监测，回到游戏前台。进入实际对局后，确认 API 显示已连接，即可等待下一次死亡。

先试一下 没开游戏也可以在「试用与帮助」体验模拟流程；模拟模式不会自动切换真实窗口。

MADE TO STAY OUT OF YOUR WAY

自动化，也要有分寸。

01确认死亡，再切出
连续两次确认死亡后才切换。默认剩余复活时间须大于 8 秒；首次连接时已死亡，不会立即抢占窗口。
02何时回来，由你设置
默认提前 3 秒返回，支持调整为 1–10 秒；也可选择确认复活后返回，或全程只进行声音提醒。
03你切走，就让你做主
仅在 DeadTime 成功切出后安排返回。你主动切到其他窗口或回到游戏，本次自动返回即取消。
04随时停下
点击暂停或紧急停止，立即清除切换任务。默认紧急快捷键为 Ctrl + Shift + F12，以软件显示注册成功为准。

仅进程检测

无畏契约

目前只识别游戏是否运行，尚不支持死亡、复活检测或自动切换。

死亡后没有切换，先检查什么？+

确认已开始监测、自动切换已开启、返回策略不是「只声音提醒」，且游戏在前台。抖音必须已打开并匹配到唯一窗口。剩余复活时间需超过设置阈值；修改设置后请重新开始监测。查看日志可以区分「未满足条件」与「Windows 拒绝激活」。

为什么有时 Windows 不允许切换？+

Windows 的前台权限、独占全屏及应用权限差异可能阻止窗口激活。可尝试游戏无边框模式，并在设置中主动测试切换。程序会验证前台窗口并记录失败，不强行绕过系统限制，也不能保证每次切换成功。

API 何时会连接？是否需要账号密码？+

通常进入实际对局后，本地 Live Client Data API 才可用；大厅不等于已进入对局。程序无需 Riot 账号密码或令牌，不读取游戏内存、不注入、不修改游戏文件。接口不可用时会明确提示。

DeadTime 未获 Riot Games 官方认可或授权。使用前请核对适用的第三方应用政策；本版本已通过自动化与模拟测试，尚未完成真实对局验收。
